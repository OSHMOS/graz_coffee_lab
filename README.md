# ☕ GRAZ COFFEE LAB — 스타필드빌리지 운정점

> **A Seoulful Blend for Every Soul.**

그라츠커피랩 스타필드빌리지 운정점의 공식 웹사이트입니다.  
오스트리아 비엔나 커피에서 영감을 받은 시그니처 크림커피 '드롭(Drop)' 시리즈를 소개하고, 매장 정보를 안내하는 싱글 페이지 웹사이트입니다.

---

## 🖥 미리보기

| 섹션 | 설명 |
|------|------|
| **Hero** | 매장 인테리어 배경 슬라이드쇼 + 소개 |
| **Our Story** | 그라츠커피랩 브랜드 스토리 & 인테리어 이미지 슬라이더 |

| **Virtual Brewer** | 드롭 음료 레이어 구성을 시각적으로 체험하는 인터랙티브 브루잉 |
| **Visit Us** | 운영시간 · 주소 · 주차 안내 · 네이버 지도 & 인스타그램 링크 |

## ✨ 주요 기능

### 🎠 배경 슬라이드쇼
히어로 섹션과 스토리 섹션에서 실제 매장 인테리어 사진이 자동 전환됩니다.

### 🧪 가상 커피 브루잉 (Virtual Brewer)
너티드롭 · 흑임자드롭 · 말차드롭 레시피를 선택하면 컵 안에 레이어가 차오르는 애니메이션이 재생됩니다.

### 🟢 실시간 영업 상태
현재 시각 기준으로 영업 중 / 라스트오더 / 영업 종료 상태를 헤더에 자동 표시합니다.

### 📱 반응형 디자인
모바일 · 태블릿 · 데스크톱 모든 화면 크기에 최적화되어 있습니다.
